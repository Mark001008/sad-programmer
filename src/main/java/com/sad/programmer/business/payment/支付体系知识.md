# 支付体系知识

> 本文档梳理中国支付体系的全景知识，涵盖监管机构、清算机构、支付机构、银行体系、财务公司定位，以及支付业务中涉及的所有核心术语。

---

## 一、监管机构

### 1.1 中国人民银行（央行）

| 项目 | 说明 |
|------|------|
| **全称** | 中国人民银行（People's Bank of China, PBC） |
| **定位** | 中央银行，金融体系最高监管者 |
| **支付相关职责** | 制定支付结算规则、监管支付机构、管理支付系统、维护支付市场秩序 |
| **核心权力** | 颁发《支付业务许可证》（支付牌照）、制定备付金政策、处罚违规机构 |

### 1.2 国家金融监督管理总局

| 项目 | 说明 |
|------|------|
| **前身** | 中国银保监会（CBIRC） |
| **定位** | 监管银行、保险、信托、金融租赁、财务公司等持牌金融机构 |
| **对财务公司** | 颁发《金融许可证》、监管资本充足率、流动性比例等指标 |
| **对银行** | 审批银行设立、监管银行业务合规 |

### 1.3 中国支付清算协会

| 项目 | 说明 |
|------|------|
| **定位** | 支付行业自律组织，央行主管 |
| **职责** | 制定行业自律规范、处理支付纠纷、组织行业培训 |
| **会员** | 银行、支付机构、清算机构等 |

## 二、清算机构

### 2.1 中国银联（China UnionPay, CUP）

| 项目 | 说明 |
|------|------|
| **全称** | 中国银联股份有限公司 |
| **成立** | 2002年，经国务院同意、央行批准 |
| **定位** | 银行卡跨行交易清算机构 |
| **核心业务** | 银行卡跨行转接清算、银联二维码支付、银联云闪付 |
| **清算模式** | 银行A → 银联 → 银行B（跨行转账/消费） |
| **卡号标识** | 以 62 开头的银联标准卡 |
| **国际业务** | 银联卡可在180+个国家和地区使用 |

**银联在支付链路中的位置**：
```
用户（工行卡）→ 商户POS → 银联转接清算 → 工行扣款 → 商户收款行入账
```

### 2.2 网联清算有限公司（NetsUnion）

| 项目 | 说明 |
|------|------|
| **全称** | 网联清算有限公司（NetsUnion Clearing Corporation） |
| **成立** | 2017年，央行推动设立 |
| **定位** | 非银行支付机构网络支付清算平台 |
| **核心业务** | 第三方支付机构的网络支付清算（支付宝、微信支付等） |
| **成立背景** | "断直连"——此前支付宝/微信直连各银行，央行无法监控资金流向 |
| **清算模式** | 支付宝 → 网联 → 银行（取代支付宝直连银行） |

**银联 vs 网联**：

| 维度 | 银联 | 网联 |
|------|------|------|
| 清算对象 | 银行卡跨行交易 | 第三方支付网络交易 |
| 接入方 | 银行 | 支付宝、微信、京东等支付机构 |
| 交易类型 | POS刷卡、ATM、银联在线 | 扫码支付、快捷支付、网银支付 |
| 成立目的 | 银行卡互联互通 | 第三方支付资金监管透明化 |
| 监管意义 | 统一银行卡标准 | 断直连，资金流可追溯 |

### 2.3 城银清算服务有限责任公司（城银清算）

| 项目 | 说明 |
|------|------|
| **定位** | 城市商业银行资金清算 |
| **业务** | 城商行汇票、城商行间资金往来 |

### 2.4 农信银资金清算中心

| 项目 | 说明 |
|------|------|
| **定位** | 农村金融机构资金清算 |
| **业务** | 农信社、农商行之间的跨行资金往来 |

## 三、支付机构（第三方支付）

### 3.1 什么是第三方支付

第三方支付是指非银行机构提供的支付服务。用户和商户之间的资金流转通过第三方支付机构中转，而非直接银行转账。

### 3.2 主要支付机构

| 机构 | 牌照类型 | 核心产品 | 市场份额（约） |
|------|----------|----------|---------------|
| **支付宝（蚂蚁集团）** | 支付业务许可证 | 支付宝APP、花呗、芝麻信用 | ~55% |
| **微信支付（腾讯）** | 支付业务许可证（财付通） | 微信支付、QQ钱包 | ~38% |
| **银联商务** | 支付业务许可证 | POS机、银联二维码 | ~3% |
| **京东支付** | 支付业务许可证 | 京东支付、白条 | ~1% |
| **拉卡拉** | 支付业务许可证 | POS机、收款码 | ~1% |
| **汇付天下** | 支付业务许可证 | 聚合支付、跨境支付 | <1% |

### 3.3 支付业务许可证（支付牌照）

| 牌照类型 | 业务范围 | 示例 |
|----------|----------|------|
| **网络支付** | 线上支付（扫码、快捷、网银） | 支付宝、微信支付 |
| **银行卡收单** | 线下POS刷卡收单 | 银联商务、拉卡拉 |
| **预付卡发行与受理** | 储值卡（购物卡、礼品卡） | 商通卡、福卡 |
| **移动电话支付** | 手机支付 | 支付宝、微信支付 |
| **数字电视支付** | 电视支付 | 少量机构持有 |
| **跨境支付** | 跨境人民币/外汇支付 | 支付宝国际、连连支付 |

**牌照价值**：一张全业务牌照市场估值约 5-10 亿元人民币（稀缺资源，央行已停止新发）。

### 3.4 备付金

| 项目 | 说明 |
|------|------|
| **定义** | 用户充值到支付账户但尚未使用的资金（如支付宝余额、微信零钱） |
| **存管政策** | 2019年1月起，100%集中存管于央行 |
| **利息** | 央行按 0.35% 活期利率支付利息给支付机构 |
| **政策前** | 支付机构可将备付金分散存入各银行，获取 3%-5% 利息收入 |
| **政策影响** | 支付宝/微信年损失利息收入约 100-200 亿元，商业模式从"吃利息"转向"收手续费+增值服务" |

## 四、银行体系

### 4.1 银行分类

| 类型 | 代表 | 特点 |
|------|------|------|
| **国有大行** | 工商银行、农业银行、中国银行、建设银行、交通银行、邮储银行 | 规模最大，网点最多，系统最稳定 |
| **股份制银行** | 招商银行、浦发银行、中信银行、光大银行、民生银行、兴业银行、平安银行、华夏银行、广发银行 | 市场化程度高，创新能力强 |
| **城商行** | 北京银行、上海银行、宁波银行、南京银行 | 区域性，服务本地企业 |
| **农商行/农信社** | 各省农村商业银行 | 服务三农和县域经济 |
| **民营银行** | 微众银行（腾讯）、网商银行（阿里）、新网银行 | 互联网银行，无线下网点 |
| **外资银行** | 汇丰银行、花旗银行、渣打银行 | 服务跨境业务 |

### 4.2 银行在支付链路中的角色

| 角色 | 说明 | 示例 |
|------|------|------|
| **付款行（发卡行）** | 用户资金来源银行 | 用户用工行卡付款，工行是付款行 |
| **收款行（收单行/入账行）** | 商户资金入账银行 | 商户资金入账到招行，招行是收款行 |
| **开证行** | 开立信用证的银行 | 国际贸易场景 |
| **代理行** | 代理其他银行办理业务 | 小银行通过大银行接入银联 |

### 4.3 银行核心系统

| 系统 | 说明 |
|------|------|
| **核心银行系统（CBS）** | 银行最核心的系统，管理账户、存款、贷款、支付 |
| **支付系统** | 对接央行支付系统（CNAPS）、银联、网联 |
| **信贷系统** | 贷款审批、发放、还款管理 |
| **风控系统** | 交易监控、反洗钱、反欺诈 |

## 五、集团财务公司

### 5.1 财务公司定位

| 项目 | 说明 |
|------|------|
| **性质** | 非银行金融机构（持牌） |
| **监管** | 国家金融监督管理总局 |
| **牌照** | 《金融许可证》（非银机构） |
| **服务对象** | 仅限集团及其成员单位（不能对外营业） |
| **本质** | 集团内部的"银行"，但不能吸收公众存款 |

### 5.2 财务公司 vs 银行 vs 第三方支付

| 维度 | 银行 | 第三方支付 | 集团财务公司 |
|------|------|-----------|-------------|
| **牌照** | 银行牌照 | 支付牌照 | 金融许可证（非银） |
| **监管** | 金融监管总局 | 央行 | 金融监管总局 |
| **服务对象** | 公众 | 公众/商户 | 集团成员单位 |
| **存款** | 可吸收公众存款 | 不可吸收存款（备付金） | 仅吸收成员单位存款 |
| **贷款** | 可向公众放贷 | 不可放贷 | 仅向成员单位放贷 |
| **支付** | 跨行转账 | 网络支付 | 内部转账结算 |
| **清算** | 接入银联/网联 | 接入网联 | 内部清算+银企直连 |

### 5.3 财务公司的支付链路

```
成员单位A（活期存款账户）
    ↓ 内部转账
财务公司内部账务系统
    ↓ 内部记账
成员单位B（活期存款账户）

---

成员单位A（活期存款账户）
    ↓ 资金归集
财务公司归集账户
    ↓ 银企直连
银行（备付金账户）
    ↓ 跨行转账
外部银行账户
```

## 六、央行支付系统

### 6.1 大额实时支付系统（HVPS）

| 项目 | 说明 |
|------|------|
| **全称** | 大额实时支付系统（High Value Payment System） |
| **特点** | 逐笔实时全额清算，金额无上限 |
| **运行时间** | 工作日 8:30-17:00 |
| **适用场景** | 大额资金转账、银行间资金调拨、跨境支付 |
| **处理时效** | 实时到账（秒级） |
| **参与者** | 银行、财务公司等金融机构 |

### 6.2 小额批量支付系统（BEPS）

| 项目 | 说明 |
|------|------|
| **全称** | 小额批量支付系统（Bulk Electronic Payment System） |
| **特点** | 批量处理，净额清算 |
| **运行时间** | 7×24小时 |
| **适用场景** | 代发工资、代扣水电费、个人转账 |
| **处理时效** | 批量处理，通常 T+1 到账 |

### 6.3 网上支付跨行清算系统（超级网银/IBPS）

| 项目 | 说明 |
|------|------|
| **全称** | 网上支付跨行清算系统（Interbank Payment System） |
| **别名** | 超级网银 |
| **特点** | 7×24小时实时到账，支持跨行实时转账 |
| **适用场景** | 个人网银转账、第三方支付快捷支付 |
| **处理时效** | 实时到账 |
| **单笔限额** | 通常 5 万元（各银行自行设定） |

### 6.4 人民币跨境支付系统（CIPS）

| 项目 | 说明 |
|------|------|
| **全称** | 人民币跨境支付系统（Cross-border Interbank Payment System） |
| **成立** | 2015年 |
| **定位** | 人民币跨境清算的"高速公路" |
| **参与者** | 境内外银行、财务公司 |
| **适用场景** | 跨境贸易人民币结算、跨境投资 |

## 七、支付方式分类

### 7.1 按场景分类

| 支付方式 | 说明 | 典型场景 |
|----------|------|----------|
| **扫码支付** | 用户扫商户码 / 商户扫用户码 | 超市、餐饮、地摊 |
| **快捷支付** | 绑定银行卡，一键支付 | 电商购物、APP充值 |
| **网银支付** | 跳转银行网银页面操作 | 大额支付、对公转账 |
| **POS刷卡** | 银行卡在POS机上刷卡/插卡/挥卡 | 线下商户 |
| **NFC支付** | 手机靠近POS机感应支付 | Apple Pay、华为Pay |
| **代扣/代付** | 授权后自动扣款 | 水电费、会员续费 |
| **转账** | 账户间直接转账 | 个人转账、企业付款 |

### 7.2 按账户类型分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **余额支付** | 使用支付账户余额 | 支付宝余额、微信零钱 |
| **银行卡支付** | 直接从银行账户扣款 | 储蓄卡、信用卡 |
| **信用支付** | 先消费后还款 | 花呗、信用卡、白条 |
| **预付卡支付** | 使用预付卡余额 | 商通卡、公交卡 |

## 八、核心术语表

### 8.1 交易类术语

| 术语 | 英文 | 说明 |
|------|------|------|
| **收单** | Acquiring | 商户通过支付机构收取用户款项 |
| **发卡** | Issuing | 银行向用户发行银行卡 |
| **转接** | Switching | 清算机构在付款行和收款行之间转接交易信息 |
| **清算** | Clearing | 计算各方应收应付金额（轧差） |
| **结算** | Settlement | 实际资金划转 |
| **轧差** | Netting | 多笔交易汇总后计算净额 |
| **代付** | Disbursement | 支付机构代替商户向用户付款（提现、退款） |
| **代扣** | Direct Debit | 授权后支付机构代替商户从用户账户扣款 |
| **退款** | Refund | 已支付金额原路退回 |
| **冲正** | Reversal | 交易异常时撤销已完成的交易 |
| **退货** | Return | 商品退货后资金退回 |

### 8.2 账户类术语

| 术语 | 英文 | 说明 |
|------|------|------|
| **备付金** | Reserve Fund | 用户充值到支付账户但未使用的资金 |
| **中间账户** | Suspense Account | 支付过程中资金的临时存放账户 |
| **过渡户** | Transit Account | 资金从A到B的中间过渡 |
| **子账户** | Sub-account | 主账户下的分账户（如资金池子账户） |
| **虚拟账户** | Virtual Account | 不对应实体银行卡的账户 |
| **电子钱包** | E-wallet | 支付账户的通俗叫法 |

### 8.3 机构类术语

| 术语 | 英文 | 说明 |
|------|------|------|
| **发卡行** | Issuer / Issuing Bank | 发行银行卡的银行 |
| **收单行** | Acquirer / Acquiring Bank | 为商户提供收单服务的银行 |
| **特约商户** | Merchant | 与支付机构签约的商户 |
| **持卡人** | Cardholder | 银行卡持有人 |
| **支付机构** | Payment Institution | 持有支付牌照的非银行机构 |
| **清算机构** | Clearing House | 提供清算服务的机构（银联、网联） |
| **资金存管银行** | Custodian Bank | 存管备付金的银行 |

### 8.4 技术类术语

| 术语 | 英文 | 说明 |
|------|------|------|
| **对账** | Reconciliation | 核对本地记录与渠道记录是否一致 |
| **长款** | Overage | 本地有记录，渠道无记录（多收了钱） |
| **短款** | Shortage | 本地无记录，渠道有记录（少收了钱） |
| **差错处理** | Error Handling | 发现对账差异后的处理 |
| **退汇** | Return | 银行退回已汇出的资金（收款账户异常） |
| **挂账** | Suspense | 资金无法入账，暂挂中间账户等待处理 |
| **抹账** | Reversal | 撤销当日已完成的交易 |

### 8.5 风控类术语

| 术语 | 英文 | 说明 |
|------|------|------|
| **反洗钱** | AML (Anti-Money Laundering) | 防止利用支付系统洗钱 |
| **KYC** | Know Your Customer | 了解你的客户（实名认证） |
| **可疑交易报告** | STR (Suspicious Transaction Report) | 发现可疑交易向央行报告 |
| **大额交易报告** | LTR (Large Transaction Report) | 单笔/累计超过阈值的交易报告 |
| **交易监测** | Transaction Monitoring | 实时监控交易行为 |
| **黑名单** | Blacklist | 被标记为高风险的账户/IP/设备 |
| **白名单** | Whitelist | 被标记为可信的账户/IP/设备 |

### 8.6 财务公司专用术语

| 术语 | 英文 | 说明 |
|------|------|------|
| **成员单位** | Member Unit | 集团下属子公司（财务公司的服务对象） |
| **资金归集** | Cash Pooling / Fund Concentration | 将成员单位分散资金集中到财务公司 |
| **资金下拨** | Fund Allocation | 财务公司向成员单位拨付资金 |
| **银企直连** | Bank-Enterprise Direct Connection | 财务公司系统与银行系统直连 |
| **内部结算** | Internal Settlement | 集团内成员单位之间的资金清算 |
| **司库** | Treasury | 集团资金管理部门，负责资金计划和调度 |
| **头寸** | Position | 某时点的资金余额 |
| **同业拆借** | Interbank Lending | 金融机构之间的短期资金借贷 |
| **协定存款** | Agreement Deposit | 约定留存金额和利率的活期存款 |
| **委托贷款** | Entrusted Loan | 委托方提供资金，财务公司代为发放的贷款 |
